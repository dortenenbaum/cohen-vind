פרוטוטייפ חי של אתר המשרד, נבנה מ־Section 2 בקובץ הפיגמה
`7adcdSMyyihCUZqLSlUlCp` (עמוד "web design").

## הרצה

הכל קובץ אחד + נכסים סטטיים. אין build, אין תלויות.

```bash
python3 -m http.server 8747
```

ואז `http://localhost:8747`.

## הערות טכניות

- **פונט**: SimplerPro_V3 מוטמע מקומית. הלוגוטייפ בפיגמה הוא
  Narkiss Block Bold — אין אצלנו, מוחלף ב-SimplerPro Bold.
- **מפת גוגל**: בראש הסקריפט יש `GOOGLE_MAPS_KEY`. עם מפתח תקף
  ומארח שלא חוסם את `maps.googleapis.com`, סקשן המפה עובר למפת
  גוגל חיה. בלי מפתח הוא מציג תצריף מכויל עם גרירה וזום.
- **קואורדינטות**: הפינים מחושבים מ-lat/lng אמיתיים דרך
  טרנספורמציית מרקטור שהותאמה לתצריף.
- **אנימציות**: חשיפת שורות במסכה וחשיפת תמונות בבלוק צבע,
  כולן מכובות תחת `prefers-reduced-motion`.

## מה עוד לא נעשה

- שפת האייקונים בכרטיסי החזון היא הצעה ראשונה, טרם אושרה.
- **תמונות הצוות הן דמה ויש להחליף אותן לפני עלייה לאוויר.** 18 הדיוקנאות
  ב-`assets/team/` הם צילומים של אנשים אמיתיים ממשרד אחר (pattersons.com),
  ששימשו כמציין מקום בהסכמת הלקוח. הם מוצגים בעמוד הצוות כצוות כהן וינד.
  להחלפה: החליפו את הקבצים באותם שמות, או ערכו את הערך השלישי בכל שורה
  ב-`TEAM_ROLES`.
- הלוגואים בעמוד אודות הם מלבנים אפורים, כמו בפיגמה.
- תמונת המשרד בעמוד הבית (`.shopfront`) היא דמה מסט הקריירה.
- עמוד "צרו קשר" לא נבנה.
